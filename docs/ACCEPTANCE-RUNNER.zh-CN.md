# 统一验收与恢复

入口 `ensp-fusion-accept` 将现有16个工具编排成一次独立验收，不增加 MCP 工具数量。

```powershell
node bin/ensp-fusion-accept.mjs run examples/acceptance-plan.json C:/labs/ensp acceptance-runs
node bin/ensp-fusion-accept.mjs status C:/labs/ensp/acceptance-runs/<run-id>
```

计划为 `version:1`、`deadline_ms` 和 `steps[]`。每一步包含唯一 `name`、现有工具 `tool`、`args`，可选 `repeat`、`interval_ms`、`cleanup:{tool,args}`。探测必须自行断言业务结果：例如 `ensp_cli.expect`、`ensp_labtest` 或 `ensp_services` 的预期值。只有工具调用成功不能替代业务断言；不支持通过 `expect_ok:false` 将执行失败判为通过。

CLI 在执行前检查整份计划的工具、公开参数类型、必需字段、枚举、未知字段和引用顺序；可以直接定位端口的静态 CLI 批次还预检命令与正则。路径、设备能力、运行时引用及业务结果仍在执行时验证。不得把此预检称为配置可用性保证。

数值断言应使用完整行或数值边界。例如零丢包使用 `"/^\\s*0(?:\\.0+)?% packet loss\\s*$/m"`，并检查发送/接收数量。普通字符串按文档是子串匹配，`0.00% packet loss` 本身也可能出现在 `100.00% packet loss` 的末尾，不能单凭该子串宣告零丢包。LLDP/角色等多字段状态同样应联合匹配明确的接口及状态。

每次使用时间戳加 UUID 创建新目录，独占创建步骤证据、JSON 汇总、Markdown、CSV 和事件日志；已失败的运行不会被成功重试覆盖。日志使用共享凭据脱敏。调用层或嵌套业务结果 `ok:false` 都会使验收失败。报告写入失败不能留下 PASS 汇总；无法写入汇总时 CLI 退出失败，应检查已有事件和变更日志。

清理在变更调用前登记，失败、超时或可捕获的取消发生后按后进先出执行，清理使用独立于取消信号的执行路径。必须为部分执行也可能发生的变更提供恢复命令。清理只有执行成功后才允许整轮 PASS。可使用 `${run_dir}` 和 `${steps.<name>.<field>}` 引用此前结果；清理可引用本步骤结果，例如 `change_journal`。若调用抛错而没有返回日志路径，该引用无法解析，清理会明确报错；需要能够处理此情况的显式恢复方案。

Ctrl+C/SIGTERM 请求停止后续步骤。当前设备工具不能硬取消正在执行的命令，验收期限也是停止后续调度的期限，实际结束可能晚于该期限；在途命令依赖其自己的连接/命令超时。清理不受该期限限制。强制终止进程、断电和系统崩溃不能执行 JavaScript finally；`status` 在原 PID 已退出时将未完成运行显示为 INTERRUPTED，不自动重放配置。PID 被复用时保守保留未完成状态，需人工检查，不将其判为通过。

恢复入口仍为 `ensp_cli recover_from`。新变更日志保存成功的变更后配置指纹和设备软件/型号/sysname 指纹。恢复在同一控制台锁内重新读取配置和版本；身份不同或配置漂移时，在恢复命令之前拒绝执行，返回 `recovery_verified` 说明通过的校验。指纹依据未经脱敏的配置计算，日志只存哈希；凭据变化也能被检测。缺少 guard 的历史记录及不完整的变更后快照拒绝自动恢复。没有跳过校验的 force 选项。

此身份校验不等于设备序列号或加密硬件身份：同型号、同版本、同名、同配置的克隆不能区分。完整配置指纹也会保守拒绝无关配置变化。应审阅当前状态并重新制定恢复计划，不能修改 guard 让旧计划勉强通过。配置行缩进、已识别的异步日志不参与指纹；已复现的 DATASYNC、LLDP、PHY 日志与配置同一行时保留真实配置后缀。

GUI启动/停止之前会验证拓扑中所有控制台设备的端口和身份。空名称设备仍显示在库存中，但不允许它被静默跳过后宣告端口检查通过。原生保存后发现空名称时，应核对GUID和原始清单再修复拓扑，保留原文件，不随意删除设备。控制台就绪与接入端口STP转发、服务已启动是独立条件，正式业务验收必须继续等待并断言后者。

2026-11-12 的独立真实验收台：S5700 双链路连接原生 PC、Client、Server，业务网段10.77.0.0/24。HTTP 使用显式80端口，DNS accept.lab 指向10.77.0.100，FTP 匿名二进制下载并校验SHA256。协议证据来自 eNSP 客体 UDP 隧道内的真实 DNS/TCP，不以宿主机服务探测代替。具体结果见同级实验项目 `docs/PRIORITY-COMPLETION-20261112.zh-CN.md`；历史动态 ARP 首包问题不因这些独立结果而改判。
