## 兼容变化

- 继续保持 19 个工具、2 项技能及原有结果字段。peer 精确支持 rc.1/rc.3/rc.5，开发依赖与锁文件仍用 rc.3。新增 observedAt、unknownPorts、retrySuppressed/retryReason，不把附加证据升级成业务成功。
- 原来缺参数或未知按键可能在前序操作后才报错，现在整批拒绝。截图 path 是兼容别名，out/path 不一致时拒绝。显式超时字段与暂停仍遵循原有单位和范围。
- 启动/停止原来最多自动投递两次，现在一次；后续请求需要先观察当前状态。ready attempts 记录每设备尝试次数，新调用重新探测，不引入永久端口黑名单。
- 旧 ensp_status 没有 observedAt 时，安装文件仍可单独核验，但提供该旧结果不能得到运行通过。默认允许最多五秒未来时钟偏差；这不认证结果来源，也不证明实时连接。
- 等待关闭时，探测超时不再等价于端口关闭。timeout_ms:0 表示一次 TCP 探测，探测自身最多约 700ms，仍受总预算约束。
