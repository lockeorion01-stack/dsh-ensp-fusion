# 布局检查规则与已知原生字段

这份参考给出绘图决策依据；字段来自本机原生样例和本次日志，不宣称适用于所有 eNSP 版本。

## 占位框与层级

每个前景对象保存稳定 ID、对象类型、关联对象、文本、字体、几何边界和测量来源。中文、长设备名和不同字体需要实测宽度，不能只按字符数计算。

建议检查：

- 文本与文本、图标与文本的硬覆盖。
- 无关连线穿过标签或图标。
- 关联连线附近存在多个无法区分的编号/端口名。
- 出界、裁切、实际不可读的字号。
- 平行链路重叠到不能辨识。

保护间距按字体、DPI 和本机样例校准。背景色块与其内容有意重合；相关连线与端口的连接也属于预期。必要连线交叉列为可读性问题，不把所有交叉都标成网络错误。

局部修正优先移动当前标签，再增加设备周边留白/层间距，必要时扩大画布。图面要求不允许删链或改变设备身份。全图总览放不下时提供总览与局部细节。

## 本机已观测字段

| 对象 | 已观测字段 | 注意 |
| --- | --- | --- |
| dev | cx、cy、edit_left、edit_top | 图标位置和名称锚点分开；不要只改其中一项 |
| line | srcDeviceID、destDeviceID；其内 interfacePair | 逻辑端点和端口声明必须保留；注意一个 line 中可能有多个 interfacePair |
| interfacePair | srcIndex、tarIndex 或 destIndex；部分样例含 BoundRect 字段 | 几何字段的位置和含义需按实际样例确认，不假定都在 line 起始标签 |
| shapes/shape | type、filloption、color、upleftcorner、width、height、borderStyle、borderWidth | 层次、颜色编码和透明性按目标版本验证 |
| txttips/txttip | left、top、right、bottom、content、fontname、fontstyle、editsize、txtcolor、txtbkcolor、charset | 大小字段不是已经证实的像素字号；中文需编码及原生截图双检 |

直接文本补丁可能保留未知节点，也可能匹配错误层级；整体 XML 重序列化也可能改变未知扩展。选用经过验证的受控方法，并比较完整语义清单和布局字段白名单。

## 本次失败样例的检查重点

21 设备/29 条 line、19 shape、22 txttip 的工程中，Core-LSW1/Core-LSW2 各方向的接口名最密集，设备名紧贴下行出口。修图先核对这两个区域。

颜色与中文标题已能写入原生工程，端口文字仍有覆盖。增加背景色不代表完成避让。先前重排脚本还发生 newpos 赋值移出循环的问题；检查锚点必须覆盖所有有连线的设备，不能只验证程序打印成功。

另有多张名为 fixed/final 的截图与旧图哈希完全相同。保存路径和文件名不是改图成功证据，需观察对象位置、实际视口与原生回读。
